# 📦 MedERP — Shared TypeScript Package

This package (`@mederp/shared`) contains shared TypeScript interfaces, type definitions, and API envelopes used by both the NestJS backend and Next.js frontend.

---

## Exports
- `UserRole`, `RoleType`
- `ApiResponse<T>`, `PaginationQuery`
- `IUser`, `ITenant`
- `IStudent`, `IFaculty`
